**功能精简说明（2026-10-08）**

本次以论文问答、跨论文综合和可靠的主题调度为核心，简化自动个性化与重复实现。

后续已完成 [Web 入口统一](web-unification-20261008.md)。下文记录第一轮精简时的状态，其中 CLI 入口和命令已被 Web 操作取代；当前使用方式以项目 README 为准。

| 调整 | 现在的行为 |
| --- | --- |
| 自动偏好推断 | 已移除模型抽取与自动持久化。通过 Web「研究设置」保存语言、格式、风格和深度；本轮明确输出要求可临时覆盖，研究结束不会改写默认偏好 |
| 自动长期记忆候选 | 新研究不再生成候选。报告下方「保存研究笔记」可填写内容，或填入本轮报告后编辑保存 |
| CLI 退出确认 | 退出不再询问是否保存记忆。`/note 内容` 主动保存笔记，`/save-note` 保存本轮报告 |
| Skills | 删除 YAML 技能加载与关键词路由，改为 `report_templates.py` 中的论文问答/文献综述写作模板 |
| MCP | 移出核心依赖；需要时安装 `requirements-mcp.txt`，保留已有 MCP 工具和启动入口 |
| 图执行降级 | LangGraph 作为必需依赖，删除 `SimpleCompiledGraph`；保留原有图节点与最大执行步数限制 |
| 重复研究逻辑 | 两条运行路径共用 `agent/research_service.py` 的证据归属、摘要笔记、全文笔记、证据反思、章节写作和报告拼接 |
| 侧栏 | 合并为「来源证据」和「研究状态」，证据归属与工具轨迹按需展开 |

短期会话压缩、已保存笔记召回、论文笔记存档和检查点继续保留。历史 `pending_memory_candidates` 不会被批量清除，原 `/memories` API 仍可访问和确认旧候选。现有数据库无需手工迁移。

CLI 的单篇问答/原图路径与 Web 的主题调度仍有各自入口。共享服务负责分析与写作；调度器继续负责有界并发、动态追加/取消、代次校验、指令幂等和恢复。此次没有把并发调度改写成串行图，也没有删除单篇问答。

共享反思统一了一个原有差异：最后一轮仍检查证据，达到上限记录 `round_limit` 并保留缺口；不会因为轮数耗尽而设置“证据充分”。空章节生成统一报错。报告写作继续在章节之间检查取消，聚合提交仍受原有终态与代次保护。

输出偏好随调研快照保存，恢复时沿用该次调研的偏好。Web 偏好设置面向当前单用户设计中的 `default` 用户；CLI 使用自定义 `--user-id` 时继续读取该用户自己的记录。

使用方式：

```powershell
# 核心应用（LangGraph 是必需依赖）
python -m pip install -r requirements.txt
python app.py

# 可选 MCP 扩展
python -m pip install -r requirements-mcp.txt
python -m mcp_server.server

# 在网页完成研究后，点击「保存研究笔记」
```

新增 API：

| 接口 | 用途 |
| --- | --- |
| `GET /api/settings/preferences` | 读取默认输出偏好 |
| `POST /api/settings/preferences` | 显式保存 `language`、`format`、`tone`、`depth`；不从报告推断 |
| `POST /api/sessions/{session_id}/notes` | 保存用户提交的 `{"content":"笔记正文"}`；空白与超过 20,000 字符的内容会被拒绝 |
