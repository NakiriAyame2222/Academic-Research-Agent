# Web 统一说明（2026-10-08）

Web 现在是唯一研究交互入口。`python app.py` 只启动 FastAPI 与构建后的前端，不再进入终端聊天循环。主题研究统一由 Web 任务管理器调用异步调度器，论文问答使用研究图；证据分析与写作继续复用共享服务。

## 原 CLI 能力的去向

| 原操作 | 现在的操作 |
| --- | --- |
| 位置参数、`--chat` | 在网页输入框提交问题 |
| `--file` | 上传 PDF/MD/TXT，或通过「已有论文」选择论文库文件 |
| `--top-k` | 「本次检索设置」覆盖数量，留空使用「研究设置」里的默认值 |
| `--rebuild-index` | 选中论文后勾选本轮开始前重建该论文索引；主题研究自动管理各子主题的证据索引 |
| `--resume`、`--session-id` | 历史会话继续追问；中断主题研究点击「继续执行」 |
| `--output`、`--show-sources` | 页面下载 Markdown、查看来源证据与调试详情；论文问答也自动生成可下载结果 |
| `/note`、`/save-note` | 「保存研究笔记」，可以填入本轮报告后编辑保存 |
| `--model`、`--api-key`、`--base-url`、`--save-config` | 在「研究设置」中保存；启动时仍可使用环境变量或 `--config-file` 加载已有配置 |
| `--serve-web` | 已不需要，直接运行 `python app.py` |
| `--serve-mcp` 与 MCP 参数 | 可选扩展使用 `python -m mcp_server.server` 独立启动 |

启动器保留 `--web-host`、`--web-port`、`--config-file`。已移除的参数会返回命令用法错误，不会静默忽略。Web 继续采用单用户 `default`；旧自定义用户记录保留在数据库中，未新增多用户登录或用户切换功能。

## 代码与状态

`initialize_app`、`run_research` 和意图/路径辅助函数从 `app.py` 移入 `agent/runtime.py`。API、测试与诊断脚本同步调整导入；启动器不再被研究后端反向依赖。内部研究图仍用于问答和既有诊断基准，它不是独立用户交互入口。

「已有论文」使用现有 `GET /api/papers`，列表支持刷新、空状态和读取失败提示。检索数量通过 `POST /api/sessions/{id}/research` 的 `top_k` 传递，限制为 1–20；主题研究修正了过去固定使用 4 的默认值，并把数量写入快照，恢复时沿用原任务值。

重建选项仅用于所选论文，成功提交后自动取消，避免每轮重复重建。会话查询增加 `selected_file`，从检查点恢复论文选择；新会话清空选择和本次检索参数。论文问答的 Markdown 文件由服务端按任务生成，下载使用现有报告接口。

无需迁移或清空现有论文、索引、报告和数据库。旧主题任务快照没有 `top_k` 时沿用当前默认值。
